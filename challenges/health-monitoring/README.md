# ASTRA — Astronaut Health Monitoring

Status: initial concept under exploration by ASTRODEGEN.

## Proposed direction

Explore an offline-first prototype for astronaut health monitoring, including:

- Personalized physiological baselines.
- Time-series anomaly detection.
- Synthetic mission simulation.
- An interactive dashboard.

Python and Streamlit are proposed technologies; no dependencies or implementation have been added yet.

## Layout

- `docs/`: challenge requirements, research, and design notes.
- `src/`: implementation when development starts.
- `tests/`: automated tests when behavior is implemented.

## Next steps

1. Record the official challenge title, URL, requirements, and judging criteria once selected.
2. Agree on the minimum demo and responsibilities.
3. Identify datasets and document their origins and limitations.
4. Implement the prototype and validate its behavior.

Keep simulated and real data explicitly labeled and separate. Use synthetic data for the initial demo. This project is an exploratory prototype, not a clinically validated medical system.
