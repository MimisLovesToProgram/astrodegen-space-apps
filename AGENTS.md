# Writing for this project

Write all project content in English. This includes documentation, interface text, code comments, commit messages, and pull request descriptions.

Use natural, clear English that sounds like a person explaining the work to a teammate. Prefer familiar words, direct sentences, and concrete explanations. Avoid inflated language, generic promotional claims, and repetitive boilerplate.

Use prose for explanations. Use lists, tables, and technical notation when they make the information easier to understand. Keep code, commands, file paths, and identifiers in their appropriate technical form.

Describe the project's actual state accurately. Distinguish planned features from implemented behavior, and clearly identify simulated data.
